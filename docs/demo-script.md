## 3. Video Recording Guidelines & Technical Checklist

For the team member recording the 3-minute submission video:

### Recording Setup
- **Software:** OBS Studio, Loom Desktop, or Camtasia.
- **Resolution:** 1920x1080 (1080p, 16:9 widescreen).
- **Frame Rate:** 60 FPS (or smooth 30 FPS minimum) for fluid map panning and waveform animations.
- **Audio:** Dedicated microphone with noise suppression (zero echo, clear voiceover).
- **Browser:** Chrome / Edge maximized in fullscreen (F11 or hidden bookmarks bar), zoom level set to 100%.
- **Pre-Recording Action:** Click "Reset Simulation" before hitting record so state starts cleanly at T-0.

### Video Hosting & Submission Links
- **Primary Hosting:** YouTube (Set as **Unlisted** or **Public**).
- **Backup Hosting:** Google Drive / Loom with link sharing set to *"Anyone with the link can view"*.
- **Submission Portal Entry:**
  - **Video Walkthrough URL:** `https://youtu.be/nigehbaan-demo` *(or uploaded Loom/Drive link)*

## 4. "If Something Breaks" Contingency Fallback Plan

| Potential Failure Point | Root Cause During Demo | Instant Fix / Fallback Action | What to Say to Judges |
| :--- | :--- | :--- | :--- |
| **Gemini API Call Times Out or Fails** | Rate limit, invalid key, or network drop. | The app automatically engages `heuristicExtractor.ts` and renders the *"Offline heuristic extraction (not AI)"* badge. | *"Our resilient architecture automatically failed over to our offline heuristic parser without dropping the citizen's report."* |
| **Corrupted Browser State / Messed-up Queue** | Accidental double-clicks or browser cache glitch. | Click the **"Reset Simulation"** button in the top navigation bar. | *"Let's reset to the baseline scenario using our 1-click state restore."* |
| **Internet Disconnects During Presentation** | Venue Wi-Fi outage. | The scoring engine, uncertainty radar, and state store run 100% client-side. Map tiles require internet, but sector polygons, markers, and tactical HUD remain fully functional without tiles. | *"Nigehbaan's decision-support core runs completely client-side: priority scoring, blind-spot detection, and resource allocation continue even if internet connectivity drops."* |
| **Audio File Doesn't Play** | Browser autoplay policy / audio mute. | Click the play button directly, or point to the pre-rendered scripted transcript box. | *"The waveform visualizer displays the simulated audio profile, accompanied by our verified speech-to-text transcript."* |
| **PWA Service Worker / Cache Issue** | Hard refresh or browser private mode. | PWA offline queue gracefully falls back to in-memory / localStorage storage. | *"The offline queue operates synchronously through resilient local storage persistence."* |
